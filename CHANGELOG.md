# Changelog

Todas as mudanças relevantes do LB — Personal Portfolio serão documentadas neste arquivo.

O projeto utiliza uma convenção de versionamento baseada em Semantic Versioning.

## [1.0.0] — Em preparação

Primeira versão do portfólio profissional.

### Adicionado

- Interface baseada no conceito Bento Grid.
- Apresentação profissional, formação e experiências.
- Seção de tecnologias e projetos.
- Componentes reutilizáveis utilizando React.
- Design System Ivory Minimal e Ivory Dark.
- Navegação responsiva com menu mobile.
- Alternância e persistência de tema.
- Filtros dinâmicos de projetos.
- Contadores de resultados e Empty State.
- Cópia de endereço de e-mail.
- Tratamento de falhas no carregamento de imagens.
- Skeleton Loading.
- Indicador de progresso de rolagem.
- Identificação automática da seção ativa.
- Botão para voltar ao topo.
- Recursos básicos de acessibilidade.

### Corrigido

- Inconsistências na distribuição do Bento Grid.
- Estilização e alinhamento do Header.
- Organização do Grid interno de projetos.
- Problemas identificados durante a recuperação do layout responsivo.
