## Sobre o projeto

O LB — Personal Portfolio é um portfólio profissional desenvolvido para apresentar minha trajetória, formação, conhecimentos técnicos e projetos na área de desenvolvimento de software.

O projeto faz parte da minha transição profissional para a área de tecnologia e representa a aplicação prática dos conhecimentos adquiridos durante meus estudos.

Sua interface foi planejada no Figma e desenvolvida utilizando React, JavaScript e CSS, seguindo o conceito visual Bento Grid.

## Objetivos

- Construir uma presença profissional na área de tecnologia.
- Aplicar conceitos de desenvolvimento Front-end.
- Desenvolver componentes reutilizáveis.
- Praticar arquitetura e organização de código.
- Utilizar boas práticas de versionamento.
- Documentar minha evolução como desenvolvedor.
- Apresentar projetos e competências técnicas.

## Demonstração

O projeto encontra-se em deploy na Vercel.

## Funcionalidades

- Interface inspirada no conceito Bento Grid.
- Layout adaptável a diferentes tamanhos de tela.
- Navegação responsiva com menu mobile.
- Light Mode e Dark Mode.
- Persistência da preferência de tema com localStorage.
- Filtros dinâmicos de projetos por status.
- Contadores de resultados.
- Empty State para listas sem resultados.
- Cópia do endereço de e-mail utilizando Clipboard API.
- Tratamento de falhas no carregamento de imagens.
- Skeleton Loading.
- Header sticky.
- Indicador de progresso de rolagem.
- Identificação automática da seção ativa.
- Botão para voltar ao topo.
- Recursos básicos de acessibilidade e navegação por teclado.

## Arquitetura do projeto

```text

├── docs/
├── public/
├── src/
│   ├── assets/
│   ├── components/
│   ├── sections/
│   ├── hooks/
│   ├── data/
│   ├── styles/
│   ├── App.jsx
│   ├── App.css
│   └── main.jsx
├── index.html
```

A arquitetura busca separar responsabilidades entre apresentação visual, componentes reutilizáveis, dados, lógica de funcionamento e estilos globais.
